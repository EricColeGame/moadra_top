## Moadra グッドエンディングが実際に求めるもの

まずは開発者が実際に語ったことから始めよう。Gloomsoftは*Moadra*を、「救済を求め、忘れられた惑星Protea VIの深部に埋もれた恐ろしい罪と向き合う」旅として説明している（[Gematsuによる本作のローンチ報道](https://www.gematsu.com/2026/10/moadra-launches-october-22)より）。この位置づけは重要だ。物語は単一のボタンプロンプトではなく、説明責任を軸に構築されている。エンディングが分岐するのであれば、それはほぼ確実に、Protea VIの埋もれた歴史にどれだけ徹底して関わったかによって分岐する。

本稿執筆時点で公式のエンディングチャートは公開されておらず、これは発売から1日のゲームとしては正常なことだ。隠しフラグを推測するのではなく、**Moadra グッドエンディング**を次の3つの行動の自然な結果として捉えてほしい。マップを徹底的に探索すること、Protoplasmを通じて装備を完全に進化させること、そしてスキャナーが明らかにする伝承に注意を払うことだ。

このモデルは、能力解放型メトロイドヴァニアが通常エンディングを扱う方法と一致している。ゲームが移動アップグレードの背後にルートを固定し、スキャナーの背後に秘密を隠す場合、「最良の」結末は通常、終盤の対話選択ではなく、達成度によって制限される。

| 記録すべき項目 | エンディングにとって重要な理由 | 確認する場所 |

| マップ踏破率 | 任意エリアには通常、より良い結末を制限する伝承やアップグレードが含まれる | マップ画面、および封鎖された扉に関する自分のメモ |
| 変態の進行度 | 能力や武器のティアは、終盤エリアを生き延びられるかを左右することが多い | 有機質のチャンバー |

## 準備：コミットする前に自分を整える

悪い結末に対する最も安価な保険は、最初の2時間での準備だ。**Moadra グッドエンディング**を逃すプレイヤーのほとんどは、難しい選択のせいで逃すのではない。あるエリアを突き進んだり、ユニークな資源を消費したり、唯一のセーブを上書きしたりしたせいで逃すのだ。

研究施設の深部へ進む前に実行する価値のあるチェックリストを以下に示す。

| 準備ステップ | エンディング攻略を守る理由 | 優先度 |
|---|---|---|
| 手動セーブを少なくとも3つローテーションで保持する | 完全なやり直しなしで、後戻りできない地点を巻き戻せる | 最重要 |
| 最も古いセーブを決して上書きしない | 最初のファイルは分岐検証のための安全網 | 最重要 |
| スキャナーのチュートリアルを完全に終える | X線視野は肉眼では見えない経路を明らかにする | 最重要 |
| ユニークなProtoplasmはすぐに使わず蓄えておく | 変態アップグレードは複利で効く。無駄にしたバイオマスはビルドを停滞させる | 高 |
| 封鎖された扉や到達できない足場をすべて記録する | バックトラックはこのジャンルの核となるループ | 高 |
| 変わった部屋や有機質のチャンバーをスクリーンショットに残す | ローンチ時点でコミュニティのマッピングはまだ不完全 | 中 |

もう一つの習慣：一度に1つの地域をプレイし、次へ進む前にクリアすること。メトロイドヴァニアは先を急ぐプレイヤーに罰を与える。なぜなら、飛ばしたアップグレードが帰り道のショートカットを開くものだった、ということがよくあるからだ。

## Moadra グッドエンディングを形作る4つのシステム

Gloomsoftが*Moadra*について示してきたすべては、4つの相互に絡み合うシステムを通じて動いている。それらを理解することが、慌ただしい結末と満足のいく**Moadra グッドエンディング**の分かれ目となる。

### スキャナーボットとX線視野

スキャナーは収集品トラッカーではない。ゲームの主要な情報ツールだ。生物や地形を調べ、隠された経路を露わにし、どこを歩いたかをマッピングする。積極的にスキャンしよう。スキャンした生物はコーデックスに記録されるらしく、コーデックスの深さはまさにエンディングが報いる傾向のある類のものだ。

### Protoplasmと変態

敵対生物を倒すとProtoplasmが得られ、有機質のチャンバー内でそれを消費すると変態が発動し、能力や武器が進化する。キーワードは*選択*だ。アップグレードが有限であるなら、すべての分岐にバイオマスを薄く広げると、最終盤で力不足になる。一貫したビルドにコミットしよう。

### 移動とマップ踏破

ローリング、回避、壁ジャンプ、スプリントはあなたの生存キットであり、各移動アップグレードは静かにマップを広げていく。移動系の解放を鍵として扱おう。手に入れた瞬間に、以前記録した障壁を再訪するのだ。

### ストーリービートと対話

*Moadra*は謎に寄りかかっている。敵対種に侵された研究施設、そして深部に埋もれた罪。ログを読み、通信を聴き、対話をスキップしないこと。もしエンディングがProtea VIで何が起きたかの理解にかかっているなら、注意力はメカニクスだ。

| システム | 公式の機能 | グッドエンディングでの活用 |
|---|---|---|
| スキャナーボット | X線視野、隠し経路、マッピング | 離れる前に新しい生物と部屋をすべてスキャンする |
| Protoplasm | 破壊した生物から吸収するバイオマス | 意図的にファームし、1つのビルド経路に使う |
| 変態 | 有機質のチャンバーでの能力・武器進化 | 移動と生存性のアップグレードを優先する |
| 探索 | 地表、凍てつく山頂、研究施設 | 進む前に各地域を完全にクリアする |

## Moadra グッドエンディングへの段階別ルート

以下は、コミュニティの情報が埋まっていくにつれて適応できる実践的なルート構造だ。エンディングが徹底性に報いるという前提に立っている。これはこのジャンルで最も安全な仮定だ。

| 段階 | 焦点 | 次へ進む前の成果物 |
|---|---|---|
| 序盤の数時間 | スキャナーを学び、地表をマッピングする | 地表の完全マップ、最初の変態 |
| 序盤の探索 | Protoplasmを蓄え、障壁を記録する | 2〜3段階のアップグレード、障壁リストの着手 |
| 凍てつく山頂 | 移動アップグレード、任意の寄り道ルート | 垂直ショートカットの解放 |
| 研究施設 | 伝承、スキャン、封鎖扉の片付け | コーデックスはほぼ充填、バックトラック完了 |
| 最後の降下 | 後戻りできない地点 | 手動セーブを作成しラベル付け |

最終幕のための3つのルール：

- **あらゆる降下や一方通行の落下の前に手動セーブを作成する。** これはエンディング重視のプレイで最もよくある後悔だ。
- **まず障壁リストを片付ける。** 封鎖された扉がまだ気にかかるなら、それはおそらくアップグレードを隠している。
- **最後のエリアを急がない。** 終盤ゾーンはビルド不足のキャラクターがふるい落とされる場所であり、慌てたフィニッシュこそが人々を弱い結末へと導く。

特に**Moadra グッドエンディング**を狙うなら、初回プレイはゆっくり目に時間を確保しよう。急ぐことは節約する以上の時間を費やす。

## グッドエンディングを静かに閉ざすミス

これらはどれも劇的ではない。だからこそ危険なのだ。

| ミス | 痛手となる理由 | 対処法 |
|---|---|---|
| 単一のセーブを上書きする | 別分岐を試すあらゆる機会を奪う | 手動セーブを3つローテーションする |
| 新エリアでスキャナーを無視する | 隠し経路とコーデックスの文脈を逃す | 戦う前にスキャンする |
| Protoplasmをあらゆるものに使う | 最終盤の前にビルドが薄まる | 一貫したアップグレード経路を1つ選ぶ |
| 任意の伝承を飛ばす | 物語が構築される救済の弧を損なう | ログと通信を読む |
| 封鎖された扉を通り過ぎて走る | アップグレードを永久に取り残す | 障壁リストを保持する |
| 序盤にすべての巨大モンスターと戦う | 後で必要になる資源を燃やす | 退却し、より良い装備で戻る |

もう一つ：終盤の選択が浅いプレイを修正してくれると仮定しないこと。分岐のあるメトロイドヴァニアのほとんどでは、エンディングはプレイスルー全体の要約であり、単一のプロンプトではない。土壇場の救済ボタンを期待するプレイヤーこそが、結末に失望するのが常だ。

## FAQ

**Moadra グッドエンディングは確認されていますか？**
Gloomsoftは*Moadra*を救済と、Protea VIに埋もれた罪と向き合うことを軸に位置づけており、これは複数の結末を強く示唆している。公式のエンディングチャートは公開されていないため、徹底的な探索と完全な変態を**Moadra グッドエンディング**への最良の道として扱ってほしい。

**グッドエンディングのプレイにはどれくらいかかりますか？**
エンディング重視のプレイスルーに関する公式のクリア時間は発表されていない。新しい移動能力でのバックトラックが過程の一部であるため、徹底的なプレイは一直線のクリティカルパスより明らかに長くかかると予想される。

**Moadra グッドエンディングはどのプラットフォームでも取得できますか？**
*Moadra*は2026年10月22日にPlayStation 5、Xbox Series、Switch、およびPC（Steam）で同時にローンチされたため、エンディング構造はどこでも同一のはずだ。バランス調整が終盤の難易度に影響しうるため、アップデート後はパッチノートを確認しよう。

**Moadra グッドエンディングには2周目が必要ですか？**
必ずしも必要ではない。ただし手動セーブをローテーションし続ければ、ゲーム全体をやり直すことなく終盤近くで分岐できる。その一つの習慣が、きれいな1周とイライラする3周の分かれ目となる。
